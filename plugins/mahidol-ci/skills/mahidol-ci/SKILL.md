# Mahidol CI

เลือกองค์ประกอบให้ตรงชนิดสื่อ ภาษา และหน่วยงาน รักษาเนื้อหาและรูปแบบไฟล์ตามคำขอ ใช้ SVG ต้นฉบับจากโฟลเดอร์ assets ตามตาราง

## การใช้กับ AI ต่างแพลตฟอร์ม

ใช้คำแนะนำนี้กับ AI ที่อ่านข้อความหรือไฟล์แนบได้ โดยไม่ต้องมีคำสั่งหรือเครื่องมือเฉพาะของ Codex ชื่อ skill ไม่ได้ทำให้ AI ทุกระบบโหลดไฟล์โดยอัตโนมัติ

- แบบไฟล์แนบ: แนบ SKILL.md พร้อมไฟล์ SVG ที่ต้องใช้จาก assets/ คำแนะนำใน SKILL.md ไม่ได้ฝังโค้ด SVG ไว้ในตัว
- แบบโฟลเดอร์: อ่าน `SKILL.md` และใช้ SVG จาก `assets/` ตามตาราง หากระบบรองรับการโหลด skill ให้ใช้โฟลเดอร์ `mahidol-ci` ทั้งชุด
- หากระบบอ่านไฟล์แนบไม่ครบหรือค้นพบเพียงข้อความบางส่วน อย่าอนุมานว่ามี SVG ครบ ให้ขอไฟล์ SVG เฉพาะที่ต้องใช้ หรือโค้ด SVG ของไฟล์นั้น

ตัวอย่างคำขอ: “ใช้ Mahidol CI จากไฟล์แนบ สร้างโปสเตอร์ภาษาไทยขนาด A4 สำหรับงาน [ชื่องาน] ใช้ตราพร้อมชื่อไทย–อังกฤษ และส่งเป็น [ชนิดไฟล์]”

## ปรับการทำงานตามความสามารถที่มี

ยึดประเภทงาน ขนาด ภาษา เนื้อหา และรูปแบบไฟล์ที่ผู้ใช้ระบุ ถ้าข้อมูลที่จำเป็นขาด ให้ถามเฉพาะส่วนที่มีผลต่อชิ้นงาน หากเลือกค่าเริ่มต้นได้ ให้แจ้งสมมติฐานสั้น ๆ ห้ามสร้างตราคณะ หน่วยงาน ฟอนต์ประจำองค์กร หรือกฎ CI เพิ่มขึ้นเอง

- ถ้าสร้างและส่งไฟล์ได้ ให้ใช้เครื่องมือที่มีในระบบนั้นและส่งไฟล์จริงตามคำขอ
- ถ้าเครื่องมือปลายทางไม่รองรับ SVG ให้แปลงจาก SVG ต้นฉบับด้วยเครื่องมือที่รักษารูปทรงและสี เลือกความละเอียดตามขนาดใช้งาน ไม่วาดขึ้นใหม่
- ถ้าไม่มีเครื่องมือสร้างไฟล์ ให้ส่งเนื้อหาและข้อกำหนดการจัดวางที่นำไปทำงานต่อได้ ระบุว่ายังไม่ได้สร้างไฟล์ ไม่แสดงลิงก์ดาวน์โหลดสมมติ
- ถ้าเปิดดูผลลัพธ์ไม่ได้ ให้แยกสิ่งที่ตรวจจากโค้ดได้ออกจากสิ่งที่ยังไม่ได้ตรวจด้วยภาพ ห้ามกล่าวว่าผ่านการตรวจภาพแล้ว

กฎและสินทรัพย์ในชุดนี้เป็นฐานจากไฟล์ที่ผู้ใช้จัดเตรียม ไม่ใช่การยืนยันว่าเป็นคู่มือมหาวิทยาลัยฉบับล่าสุด หากผู้ใช้ให้คู่มือทางการที่ขัดกัน ให้ชี้ข้อแตกต่างและใช้แหล่งทางการที่ตรงกับรุ่นและงานนั้น โดยไม่แก้ master เดิมเงียบ ๆ

## ข้อกำหนด

- **ห้าม flip, mirror และ rotate** ทุกองค์ประกอบ ย่อ–ขยายได้โดยรักษาสัดส่วน ห้ามยืด บีบ เอียง หรือบิดรูป
- **ใช้เฉพาะสีตามอัตลักษณ์ที่อนุญาตสำหรับองค์ประกอบนั้น** คงสีของ SVG ที่เลือก ยกเว้นเส้นโค้งสามเส้นที่เปลี่ยนสีได้ตามกฎด้านล่าง ไม่ใช้ข้อยกเว้นนี้กับโลโก้ ตัว MU หรือดอกกันภัย
- คงชุดตรา ชื่อ และ tagline ตามต้นฉบับ ห้ามแยกจัดใหม่ เปลี่ยนฟอนต์ วาดใหม่ ครอปตรา หรือเติมเงา เส้นขอบ gradient และเอฟเฟกต์
- ตรามาตรฐานพร้อมชื่อและ tagline เว้นรอบอย่างน้อย `X/4`; `X` คือความสูงตราวงกลมจริง ไม่ใช่ความสูงกรอบ SVG ขั้นต่ำตรามาตรฐาน 10 มม. สำหรับพิมพ์ หรือ 28 px สำหรับดิจิทัล เพิ่มขนาดเมื่อชื่อหรือ tagline อ่านไม่ชัด
- ชุด MU เวอร์ชันนี้มีเฉพาะตัว MU ตามคำขอผู้ใช้ ไม่มีชื่อมหาวิทยาลัยหรือ tagline; อย่าอนุมานระยะเว้นรอบจากชื่อที่ลบออก ให้ตรวจคู่มือสำหรับเวอร์ชันที่ใช้ และไม่ให้ข้อความหรือภาพอื่นชิดตัว MU
- ลายเส้นโค้ง `mu graphic device` คงทิศทางจากซ้ายล่างไปขวาบน ดอกกันภัยใช้ชุดองค์ประกอบเดิม การครอปลวดลายต้องตรงแบบที่อนุญาตและไม่ใช้กับตราหรือชุด MU
- เลือกพื้นหลังให้ตราและข้อความชัดเจน หากต้องใช้เวอร์ชันเจาะขาวหรือสีอื่นที่ไม่มีในไฟล์ ให้หา master ที่ถูกต้องก่อน ไม่ดัดแปลงเอง

## ใช้งานและตรวจผล

**ใช้ไฟล์ SVG ต้นฉบับจาก assets ตามตาราง** โดยคัดลอกไฟล์ที่เลือกไปใช้ ห้ามเขียน `path` ใหม่ ห้ามประมาณรูปทรง วาดตามภาพ trace หรือใช้ image generation สร้างทดแทน คงค่า `d`, `points`, `viewBox` และ transform ภายในตามไฟล์ต้นฉบับ ส่วนสีใช้กฎของแต่ละองค์ประกอบด้านบน หากไฟล์ขาดหรืออ่านไม่ได้ ให้แจ้งแทนการสร้างโค้ดเดา

วาง SVG แบบรักษาสัดส่วน เช่น `height: auto` หรือ fit แบบ contain ไม่ใช้ cover ตัดตรา `viewBox` ไม่ได้ยืนยันว่ามี clear space ครบ ต้องตรวจเพิ่มตอนจัดวาง และห้ามเปลี่ยนจุดเริ่มต้น viewBox โดยไม่ปรับพิกัดเส้นให้สอดคล้องกัน

ใช้ `<img>` เพื่อแยก CSS ของแต่ละ SVG หากฝัง inline ต้องแยกชื่อ id/class และตัวอ้างอิงให้ไม่ชนกัน การแปลงพิกัดที่มีอยู่ภายใน SVG เป็นส่วนของต้นฉบับ ไม่ใช่คำสั่งให้ flip/rotate ภาพตอนจัดวาง

ตรวจไฟล์ส่งออกจริง: รูปทรงและสีถูกต้อง ระยะเว้นรอบครบ ข้อความอ่านได้ ไม่ล้นหรือถูกตัด และไม่มีการ flip/rotate ส่งไฟล์ตามที่ขอพร้อมแจ้งส่วนที่ยังตรวจไม่ได้
